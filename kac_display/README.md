# KAC Display Bridge

Send arbitrary Home Assistant entity states, formatted values, bars, sparklines, camera/media pictures, SVG map entities, and uploaded static graphics to one or more devices running the KleinerAnzeigeComputer (KAC) firmware. The ingress Web UI provides searchable Home Assistant entities and aliases and configures devices, templates, pages, rows, and image slots.

The add-on uses only the documented KAC HTTP endpoints and field names. It supports all documented text-row types, automatic multi-part updates, KAC image slots 1–5, adaptive 240×240 JPEG compression, safe named templates, and persistent sparkline history.

See [DOCS.md](DOCS.md) for installation and the complete configuration reference.
