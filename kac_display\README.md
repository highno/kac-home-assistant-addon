# KAC Display Bridge

Send arbitrary Home Assistant entity states, formatted values, bars, sparklines, and local image files to one or more devices running the KleinerAnzeigeComputer (KAC) firmware.

The add-on uses only the documented KAC HTTP endpoints and field names. It supports all documented text-row types, automatic multi-part updates, KAC image slots 1–5, safe named templates, and persistent sparkline history.

See [DOCS.md](DOCS.md) for installation and the complete configuration reference.
